## Max Heap — Formulas to Remember

```text
Parent(i) = (i - 1) / 2
Left(i)   = 2*i + 1
Right(i)  = 2*i + 2
```

### Insert

1. Add element at end.
2. Compare with parent.
3. While `child > parent`:
   - Swap.
   - Move upward.

### Delete Max

1. Replace root with last element.
2. Remove last element.
3. Compare with larger child.
4. Swap downward until heap property is restored.
